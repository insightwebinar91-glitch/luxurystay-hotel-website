LuxuryStay – Hotel Booking Website

A modern, responsive luxury hotel website demonstration built using HTML, CSS and JavaScript.

Project Overview

LuxuryStay is a demonstration hotel website designed to showcase hotel rooms, facilities and booking enquiry functionality.

Features

- Responsive navigation
- Modern luxury-themed design
- Hotel room listings
- Room selection
- Booking enquiry form
- Date validation
- Contact section
- Responsive layouts

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure

- "index.html" – Website structure
- "style.css" – Styling and responsive layouts
- "script.js" – Interactive functionality
